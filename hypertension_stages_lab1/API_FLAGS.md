# Вычисляемые признаки в REST API

- `GET /api/hypertension_stages?filter=...`: только `status=опубликован`; у каждого элемента `is_owner` равно `1`, если `user_id` совпадает с текущим пользователем, иначе `0`.
- `GET /api/feed`: только опубликованные; `is_liked` равно `1`, если у текущего пользователя есть запись в `hypertension_likes` с `value=1`, иначе `0`.
- `GET /api/feed/:id` и `GET /api/feed/:id?next=true`: те же правила для `is_liked`.

Признаки возвращаются даже при значении 0, но не сохраняются в PostgreSQL (`gorm:"-"`). Текущий пользователь по-прежнему задаётся через `ds.GetCurrentUser()` и на данном этапе фиксирован в `internal/app/ds/user.go` (`CurrentUserID = 1`).

Проверка: `go test ./...` (требуется Go версии, указанной в go.mod). Миграция БД для добавления этих двух полей не нужна.
